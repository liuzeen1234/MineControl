# 三角色协作：全部支持版本实测

日期：2026-11-20。macOS arm64，Gradle 使用 Java 25；旧版游戏使用 Java 17，26.x 游戏使用 Java 25。各版本按仓库中的 Fabric 依赖构建。

三份独立测试宏分别注册 execution、detection、scheduler 角色。每个版本均在真实开发客户端和该版本测试世界的副本中运行三组场景，没有连接多人服务器，没有修改原测试世界。

| Minecraft | 正常协作/重启 | 暂停/恢复 | 调度退出联动 | 结果 |
| --- | --- | --- | --- | --- |
| [1.20.1](1.20.1/summary.json) | 14 项 | 14 项 | 6 项 | 通过 |
| [1.20.4](1.20.4/summary.json) | 14 项 | 14 项 | 6 项 | 通过 |
| [26.2](26.2/summary.json) | 14 项 | 14 项 | 6 项 | 通过 |
| [26.3](26.3/summary.json) | 14 项 | 14 项 | 6 项 | 通过 |

共 12 组场景、136 项宏内协作断言通过；外部测试器另逐组检查所有宏进程已退出、键鼠输入清空、输入隔离解除、没有未处理的宏异常。汇总及最终 jar 的 SHA-256 见 [results.json](results.json)，各目录中的 normal/pause/cascade.json 包含具体断言和生命周期事件。

验证过程：调度宏启动检测宏和执行宏，通过广播向执行宏下发指令；执行宏按住 Shift 并轻微转动视角；检测宏读取真实快照并广播，调度宏据此确认输入与视角生效，再执行停止、重启、暂停/恢复或主动退出。检测宏和调度宏均实际验证输入控制被 FORBIDDEN 拒绝。

首轮发现检测宏在停止请求与广播之间存在竞态，会将正常 STOPPING 响应打印成异常；已在测试宏中按正常停止处理，最终三份 jar 重新跑完四个版本，均无未处理异常。未为此修改正式 Mod 的实现。

三份宏均为独立 Java 17 可执行 jar，位于 `build/macros/cooperation/`。主 Mod 及隐藏 SDK 运行库均不包含这些宏，不自动预装。宏源码、构建、手动添加和重跑步骤见 [测试宏说明](../../tools/cooperation-test/README.md)。

测试通过后四个测试客户端均正常保存副本世界并退出。边界：此记录覆盖三角色协作、权限与输入/进程清理，不等同于完整挖矿、仓储、小地图联动等功能测试。
