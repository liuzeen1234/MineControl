# 鱼骨挖矿 Java 宏

源码：`java-sdk/examples/FishboneMining.java`。构建：

```sh
JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-25.jdk/Contents/Home ./gradlew --offline :java-sdk:fishboneMiningJar
```

生成 `java-sdk/build/libs/fishbone-mining.jar`。在 Minecraft 26.2 按 F8 → 添加文件，选择此 JAR 或源码 → 启动。无需 Python。源码可直接修改后重新启动；修改 JAR 的配置须重新构建并重新添加。F9 停止。

进入生存模式，主手持有镐，站在有实心支撑的起点，关闭界面。鼠标灵敏度使用 0.5，关闭 Y 轴反转；宏通过反馈校验转向，校准失败停止。启动朝向取最近的东南西北方向。生命低于 16、饥饿低于 6、工具丢失、打开界面或切换维度会停止。

## 路线与探测

- 主道宽一格、高两格，前进三格；左侧延伸五格返回，右侧延伸五格返回，再重复。正常主道保持起始高度。
- 每次开挖前探测沿开挖方向三格宽、三格高、六格长的区域。三格高度是脚部、头部、头顶一格；另外在实际开挖和行走前检查地板与周围一格。水、岩浆、`waterlogged=true` 都视为液体。
- 遇液体后按水平半径 8、16、32、50 格逐步扩大勘探，以当前高度附近的液体连通区域作为障碍。远处的矿石身份被丢弃，不能成为矿石目标。区域请求分块发送，遵守接口体积和响应大小上限。
- 在已确认安全的同一高度网格中，用 Dijkstra 搜索路径：每次移动成本为一，每个需要开挖的方块再加一。液体周围一格、无支撑处和未知区域禁止通行。这里的“最优”是当前探测网格内的最小成本，不代表整个世界的全局最优。
- 主道绕行后回到原主道向前延长线上，重新计数三格。支道绕行仍以原定五格终点为目标。50 格内边界不明或没有安全绕行路径时，主道优先左转、其次右转；支道先回到主道再转向。没有安全方向就停止。
- 区块未加载、查询失败、途中环境变化、落沙/沙砾、无支撑和不支持的方块会停止。追矿挖掉的相邻地板可用快捷栏实心方块修复，确认放置成功后才行走；自然洞穴缺口不自动搭桥。请在快捷栏保留镐与圆石等材料。本宏不自动进食或战斗。

## 矿脉与反矿透

只允许以实际挖开的方块或已经走到的矿道格为中心，查询其周围一格。矿石候选只从六个面相邻位置加入；棱、角相邻不连接。大范围液体探测即使返回矿石，也不会将它们加入候选。

挖矿前必须通过准星确认目标是第一个可见方块。挖掉矿石后，再以这个刚挖开的方块为中心查询下一层，直到没有待确认的六面相连矿石；随后回到鱼骨路线中断点。可为追矿使用上下台阶，并在追矿结束后返回主道高度。不挖自身脚下支撑，必要时先移动到安全位置。无法安全接近、存在液体或返回路径被破坏时停止，并报告待处理矿石，不宣称矿脉已挖完。

## 低耐久入口

源码顶部：

```java
static final String LOW_DURABILITY_COMMAND = "";
```

剩余耐久 **低于 50 点**触发一次，50 点本身不触发。当前为空：释放输入、记录原因并结束。填入命令后，会发送一次并结束；命令发送成功不代表服务器接受或执行成功。没有自动换镐或自动恢复。

正常结束日志为宏工作目录中的 `fishbone-last-run.log`，保留最近约一万条动作；F8 运行时标准输出也进入游戏 `logs/latest.log`，带 `[Java 宏]` 前缀。F9 强制停止时以游戏日志为准。

## 验证

```sh
./gradlew --offline :java-sdk:fishboneMiningTest
```

覆盖液体属性、探测尺寸、50 格水平边界、绕行与原线汇合、开挖成本、六面邻接、未打开空间的查询拒绝、远处矿石过滤以及 50/49 点耐久阈值。

`FishboneMiningLiveCheck` 是仅供专用本地测试世界的实机检查，使用预先搭好的场地：

```sh
./gradlew --offline :java-sdk:fishboneMiningLiveCheck -PcontrolPort=25581 -PfishboneScenario=cycle
```

场景为 `cycle`、`liquid`、`large`、`low`、`repair`，结果写入 `docs/fishbone-java-test/`。不要在外部服务器运行这些测试。

## 遇坑绕行

前方下一格缺少实心地板时，先以 8、16、32、50 格水平半径逐步探测，
在同一高度寻找有支撑、无液体且环境已知的安全路径，允许挖开侧面石壁绕过坑洞。
主道绕行后回到原直线前方至少两格处；支道以原五格终点为目标。
没有安全绕行路线时，主道尝试左转、右转，支道按现有逻辑返回；均不可行则停止。
途中逐步重新检查，不跳坑、不向未知坑底下降，也不为自然坑洞自动搭桥。
此规则针对主道和支道向前开挖；追矿挖空原返回锚点的支撑仍可能安全停止。
